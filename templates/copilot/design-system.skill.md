# Setup BC Gov design system

Use the BC Gov design system React components for all UI work in this project.

## Do this

- Prefer @bcgov/design-system-react-components for standard UI primitives.
- Reuse the established design tokens and spacing conventions.
- Match the existing design system patterns and accessibility behavior.

## Do not do this

- Do not create ad hoc button, form, or layout variants with custom styling.
- Do not invent new BC Gov colors, spacing, or typography tokens without approval.
