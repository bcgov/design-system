# AI system prompts

Each B.C. Design System library ships a bundled AGENTS.md file to help AI agents make effective use of the design system.

Add the B.C. Design System boilerplate below to an AGENTS.md file at the root of your project. This gives agents important context for using the design system, and directs them to also load the package-specific instructions for each library.
